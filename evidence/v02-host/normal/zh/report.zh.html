claude.path · 提醒

当前 PATH 未发现可调用入口；不等于机器上完全未安装。

{
  "entries": [],
  "installation_groups": 0,
  "cmd_path_candidate": null,
  "powershell_path_candidate": null,
  "resolution_model": "PATH+PATHEXT; excludes CWD, aliases and functions",
  "scan_limited": false
}

现象

PATH 未发现可选入口。

判断依据：本次限定范围中没有选中的 CMD/PATHEXT 候选。

手动复查步骤

  1. 在实际使用的 PowerShell 中运行 Get-Command codex,claude -All，核对入口。
  2. 按官方安装说明人工检查安装位置；调整后打开新终端再体检。
  3. 官方说明（手动查看）：https://code.claude.com/docs/en/setup

检查限制：不扫描磁盘；未发现不等于未安装。

wsl.launcher · 通过

只检查系统 WSL 启动器；存在不等于组件或发行版可用。

{
  "present": true,
  "component_health": "not_checked"
}

现象

WSL 内部环境未检查。

判断依据：Windows 启动器和注册数量仅是外部观察；内部检查始终跳过。

手动复查步骤

  1. 若实际在 WSL 内使用工具，请在自己选定的发行版内单独核对安装。
  2. 仅需查看 Windows 注册列表时，可人工运行 wsl --list --quiet。
  3. 官方说明（手动查看）：https://learn.microsoft.com/en-us/windows/wsl/basic-commands

检查限制：本工具不启动发行版，也不把未安装 WSL 判为 AI 工具故障。
